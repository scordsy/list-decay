# Bundled register sample

`register-sample-2026-07-20.csv` holds 5,000 England and Wales companies incorporated between 2016 and 2021, drawn at random from the Companies House register and checked on 20 July 2026. They are the companies that were open on 1 July 2023. Only the fields list-decay reads are kept. Company names are left out.

It powers `list-decay check --demo` and `list-decay study`, which reproduce the published figures exactly with no API key.
